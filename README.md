# Ловушка для комара 🦟

Браузерная игра на TypeScript + Vite. Кликай по комарам, пока шкала «Тишина в комнате» не заполнится и персонаж не уснёт.

## Правила

- Попадание: +7 % тишины. Нужно набрать 100 %.
- Промах: −2 секунды. На всё даётся 30 секунд.
- Комары отскакивают от краёв окна, внезапно меняют курс, а красные — в рывке.
- Чем тише в комнате, тем быстрее и многочисленнее комары.
- Баланс настраивается в объекте `CFG` в `src/game.ts`.

## Запуск

```bash
npm install
npm run dev
npm run build
npm run preview
```
